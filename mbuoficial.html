Como Funciona?

O Loop

6.706 metros (4,167 milhas). Esse é o percurso que todo atleta deve completar em até uma hora.

O Recomeço

A cada hora exata, o sino toca. Quem não estiver no brete de largada pronto para o próximo loop está desclassificado.

There is no Finish

Não há segundo lugar. A corrida só termina quando resta apenas um corredor na pista para completar a volta sozinho.
